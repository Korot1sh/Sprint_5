Проект «Доска»

Описание:
Проект для автоматизации тестирования сервиса объявлений «Доска» - "https://qa-desk.education-services.ru/"

1.Регистрация новых пользователей
2.Регистрация пользователя c email не по маске
3.Регистрация уже существующего пользователя
4.Login/Logout пользователя
5.Создание объявлений (Неавторизованным пользователем/авторизованным пользователем)

Поддерживаемые браузеры:
Google Chrome

Используемые технологии:
Python 3.10+ 
Selenium WebDriver 4.0+
pytest 8.0+
